# C1.3 · Approve or archive

> C1 · Approve a new project

| Button | What happens | When |
|---|---|---|
| **Approve** | the project moves to **Open** and becomes visible to talents. | the brief is clear enough to source against. |
| **Archive** | it leaves the queue without going live. | duplicate, abandoned, or never a real project. |
| **Change Owner** | reassigns it, no status change. | somebody else should be running this one. |

> **Approve is what unblocks everybody else**
>
> Nothing downstream can start until it happens. No invitations, no applications, no interviews. A brief sitting in **In Review** is not waiting on the client, it is waiting on you.

**Not sure yet?** Leave it. There is no *needs more information* status, so the honest move is to message the client and let the project sit in the queue until they answer.
