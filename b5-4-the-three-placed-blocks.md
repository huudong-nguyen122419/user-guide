# B5.4 · The three placed blocks

> B5 · Talent · find a resource

1. **B5.4.1** — **Home** — low in the left column, below the standing FAQ cards, a **Resource** block split **Videos (n) / Documents (n)**. Do not confuse it with those FAQ cards above it: those are fixed page content, not resources, and no admin setting moves them.

   ![Resource block on the talent Home page](res-14-home-block.png)

   *B5.4.1 — Display Page = Home lands here.*

2. **B5.4.2** — **Project** — the project list under **Work**, at the bottom of the filter sidebar, past Preferred Country.

   ![Resource block on the project list](res-15-projectlist-block.png)

   *B5.4.2 — Display Page = Project lands here.*

3. **B5.4.3** — **Project Details** — a single project's page, top of the right column, beside the briefing.

   ![Resource tabs on a project detail page](res-16-projectdetail-block.png)

   *B5.4.3 — Display Page = Project Details lands here.*

4. **B5.4.4** — **The same material, twice over.** A placed resource is not removed from the Resources page — the block is a shortcut to it, sitting where the talent is already looking. Nothing is exclusive to a block.
