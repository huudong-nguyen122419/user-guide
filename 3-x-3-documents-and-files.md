# 3.x.3 · Documents & files

> 3 · Send a 1:1 email → 3.x · Edge cases

## use · Use it in compose

**📎** uploads a file from your computer; **🗂** attaches from the shared Document library (Common, Contact and Campaign filter checkboxes, **Published** files only).

![Select document](v3s-25-select-document.png)

*Use: 🗂 Select Documents: shared files (Published only).*

## make · Build the library

**Documents** (left menu) → **+ Create New**. Fill in **Name***, then **Type***, which decides the compose tab it lands under: Common, Contact or Campaign. Set **Status*** to **Draft** or **Published**; only a Published document can be attached. **Is Star** and **Is Public** are optional. Attach the **File***, then **Upload File** → **Create**. Retire with **Archived**, not delete.

![Document create form](v3s-86-document-create.png)

*Create: Name\* · Type\* · Status\* (Draft→Published) · Upload File.*
