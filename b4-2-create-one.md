# B4.2 · Create one

> B4 · Publish a resource (Admin)

1. **B4.2.1** — Click **Create New**, top right. A drawer opens over the list.

   ![Create New button](res-03-create.png)

   *B4.2.1 — Create New.*

2. **B4.2.2** — **Set *Resource Type* first**, before filling anything else in — the rest of the form changes underneath you when you touch it. Everything else is shared: **Title** (required) · **Status** · **Display Page** · **Categories** · **Published At** · **Description** · **Thumbnail**.

   | Field | Video | PDF |
   |---|---|---|
   | **Source** (Youtube · Vimeo · Internal) | required | **gone** |
   | **Video URL** | required | **gone** |
   | **Upload PDF File** | — | **required** |

   ![Create Resource form, Video type](res-04-video.png)

   *B4.2.2 — the two fields only Video has: ① Source · ② Video URL.*

3. **B4.2.3** — Switch to **PDF** and those two disappear; **Upload PDF File** takes their place and is mandatory.

   ![Create Resource form, PDF type](res-05-pdf.png)

   *B4.2.3 — Upload PDF File, the field that replaces Source and Video URL.*

4. **B4.2.4** — **Categories** offers two values — **Profile Tips** and **Interview Prep** — and a resource can carry both. This is the only field a talent can filter on, so leaving it empty makes the resource harder to find, not just untidy.

5. **B4.2.5** — **Thumbnail is optional but worth doing.** Leave it out on a PDF and the system generates one from the file's first page; that renders in the admin table, but talents get a plain placeholder card. Compare the cards in [B5.2 ↗](b5-talent-find-a-resource.md) and you can see which resources had a thumbnail uploaded.
