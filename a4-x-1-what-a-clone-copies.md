# A4.x.1 · What a clone copies

> A4 · Manage a campaign (Admin) → A4.x · Edge cases

**What a clone copies.** The **steps and their variants** come along; the **people** and every **metric** do not. The clone opens as a fresh **Draft** with 0 people. Add the audience again [(SDR Flow 6.4 ↗)](6-4-add-and-remove-people.md) before you enable it.
