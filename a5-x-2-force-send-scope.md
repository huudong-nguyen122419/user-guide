# A5.x.2 · Force Send scope

> A5 · Manage a marketing email (Admin) → A5.x · Edge cases

**Force Send only reaches reviewed contacts.** Same rule as [A3.1.3 ↗](a3-1-run-a-marketing-email.md): people the SDR never marked **Content Reviewed** stay behind. A queue smaller than the People count usually means review, not a bug — check **People** before you chase it.
