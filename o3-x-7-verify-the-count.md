# O3.x.7 · Verify the count

> O3 · Add contacts to list → O3.x · Edge cases

**Verify the count while adding.** The point here is just to **look**, you don't tick any list. Flow: (The **Segments (Lists)** page also shows the per-list **Members** column, if you'd rather check there.)

- **Select the contact(s)**: this is what makes the **Add to list** button appear (no selection → no button).

- Click **Add to list** → the **Add to list drawer** opens.

- **Verify: way A: read the Members column.** Every list in the drawer shows its **current member count** (e.g. 17072026v3 = 359). A quick eyeball: no clicks, no ticking. **Way A**: the drawer's **Members** column: each list's live count.

- **Verify: way B: open the list's detail.** **Click the list's name** → its detail opens right there → the **Members** tab shows the exact count ("Showing X of N") and the actual people. **Way B**: click the list **name** → detail opens with the live count (here 359).
