# 7.1 · Create a ME

> 7 · Manage a Marketing Email

## 7.1.4 · ⚠ Next already creates it

The marketing email is saved the moment you press **Next**. Before you have written a single line of the email. The address bar picks up an `?id=` and the list count goes up straight away (measured: All 91 → 92, Draft 57 → 58). So closing the wizard at step ② does **not** cancel anything. It leaves a named, empty **Draft** behind. If you opened it by accident, go back to the list and delete it ([A5.2 ↗](a5-2-row-actions.md)); a Draft can still be deleted. This is worth knowing before you wonder why the Draft tab keeps growing.
