# B2.x.3 · Partial submit

> B2 · Talent · log & submit timesheet → B2.x · Edge cases

**Partial submit — three days logged, only two locked in.** The submit dialog is where you **choose which days get locked**; it is not a “send everything” button. **Example:** the talent logged the **5th, 6th and 7th**, but the 7th still needs client confirmation → untick the 7th and click **Submit 2 working days**. The 5th and 6th are **locked** (dark purple); the 7th **stays light purple**, still editable and deletable, and remains in **pending submission** — ready for a later submit. Consequence: **one contract can have several submit rounds**, and Admin can issue a matching number of invoices — see [B3.x.3 ↗](b3-x-3-several-billing-rounds.md).

| Action | What happens in the dialog |
|---|---|
| Open the dialog | Every pending day is **pre-ticked**; the counter reads **“N working days selected”**. |
| **Untick** a row | That row turns from purple to **white**; the counter drops; the button rewrites itself (**Submit 1 working day**). |
| **Uncheck all** | Clears everything — handy when you only want one or two days and prefer to tick them back. |
| **Timesheet date** filter | Narrows the list to a date range, useful when the queue is long. |
