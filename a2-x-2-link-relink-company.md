# A2.x.2 · Link / relink company

> A2 · Create a single contact → A2.x · Edge cases

**Link / relink a work experience to a company.** On a contact's Work Experience, an **unlinked** row shows the company as plain text and carries a **Link company** icon. That opens a company picker. The company has to be in **Companies** already, so if you get 0 results, shorten the keyword. Clicking links it **immediately**, with a “Linked” toast to confirm. There is a bonus on top: **“Apply to N other contacts”** fixes the same mislink everywhere at once. A row that's **already linked** shows **Relink** instead, it re-points to a **different** company (company-scoped: moves every experience matched to the old company).
