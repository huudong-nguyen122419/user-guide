# A2.x.2 · Link / relink company

> A2 · Create a single contact → A2.x · Edge cases

**Link / relink a work experience to a company.** On a contact's Work Experience, an **unlinked** row (company shown as plain text) has a **Link company** icon → a company picker (the company must already exist in **Companies**; 0 results → shorten the keyword) → clicking links **immediately** (toast "Linked") → a bonus **"Apply to N other contacts"** fixes the same mislink everywhere. A row that's **already linked** shows **Relink** instead — it re-points to a **different** company (company-scoped: moves every experience matched to the old company).
