# 2.x.5 · Sort the table

> 2 · Find a target contact → 2.x · Edge cases

**Sort by Country / City / Last Contact.** **Country**, **City** and **Last Contact** are sortable columns, **click the header** to sort (click once = A→Z / oldest→newest, click again = reverse; empty values group first). Sort by **Country / City** to work one geography at a time; sort by **Last Contact** to surface who's gone quiet (feeds Flow 5).
