# A6.x.3 · No bulk status update

> A6 · Talent Active / Passive → A6.x · Edge cases

**There is no bulk status update — but two bulk actions still change the outcome.** **Bulk Actions** offers Export PDF Talents, Add to list, Remove from list, Export Talents (CSV), **Set Skip Review**, **Set Require Review** — and nothing else. Every status change is one profile at a time; for a long list, **Add to list** first and split it between people. **Set Skip Review is not cosmetic.** It flips the talent's internal status to *Skip Review*, which is one half of the automatic rule in [A6.x.1 ↗](a6-x-1-in-review-queue.md). Applying it to someone still In Review changes what **Approve** will do to them. **Set Require Review** is the opposite action.
