# B4.x.4 · The link is public

> B4 · Publish a resource (Admin) → B4.x · Edge cases

**Copy Resource Link gives you a public link.** It points at the file in S3 and **opens for anyone who has it**, no login, no membership, no paid-signup check. Every gate described in [B5 ↗](b5-talent-find-a-resource.md) applies to the app, not to that URL. Treat it as publishing to the open web: fine for something you would put on the website, wrong for anything client-confidential.
