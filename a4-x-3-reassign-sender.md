# A4.x.3 · Reassign ≠ sender

> A4 · Manage a campaign (Admin) → A4.x · Edge cases

**Reassigning does not re-point the sending account.** **Manage assignee** changes *who owns* the campaign; the **From** address still comes from the account set with the **⚙** badge [(A4.4.4 ↗)](a4-4-inside-the-campaign.md). Hand a campaign over → check both, or the new owner's replies land in the old inbox.
