# 2.x.1 · Filter by Lifecycles

> 2 · Find a target contact → 2.x · Edge cases

**Filter by Lifecycles.** Click **Lifecycles** → every value has a **✓** and an **✕**: The **Has a lifecycle / No lifecycle** radios catch contacts with/without any label; the box at the top lets you **search or type a custom value**. E.g. tick **✓ Prospect** to work only untouched people; add **✕ Opted Out** · **✕ Not Interested** to hide the dead ones. [Full Lifecycles reference → Flow 8.1 ↗](8-1-list-members-bar.md)

- **✓ include** = **keep only** contacts at that stage (show them, hide the rest).

- **✕ exclude** = **hide** contacts at that stage (drop them, keep the rest).

- Several **✓** together = **OR** — a contact matches if it's at *any* ticked stage.
