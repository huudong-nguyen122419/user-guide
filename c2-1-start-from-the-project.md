# C2.1 · Start from the project

> C2 · Source and invite talents

**On the Projects list, every row has a Send Invitations link** above the project name. Use it. It opens **Invite Talents** already filtered for that project, and the filters it sets are not obvious from anywhere else:

| Filter it sets | Why |
|---|---|
| **Statuses = Active** | Passive talents are not looking for work ([A6 ↗](a6-a-6-the-rule-that-runs-today.md)). |
| **Invited Status = Not Invited** | so you cannot invite the same person twice. |
| **Seniority Levels** | taken from the project brief. A Manager-level mandate arrives filtered to **Manager** and **Senior**. |

> **Opening Invite Talents from the left menu is not the same thing**
>
> Go in that way and you get the talent database with **no project attached and none of those filters**. Everything still looks normal, so the mistake is quiet. **Always start from the project row.**
