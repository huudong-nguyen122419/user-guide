# A4.6 · Run the campaign (Enabled)

> A4 · Manage a campaign (Admin)

## A4.6.1

Open **Campaigns** → find the campaign (the SDR sets it **Draft → Scheduled**; you run it).

## A4.6.2

Flip the **Enabled** toggle on its row. That turns the sending **on**; the status moves through **Running → Finished** (or **Paused** if you flip it off).

![Enabled toggle on the campaigns list](sdrx-camp-20-enabled.png)

*A4.6: the Enabled toggle on the campaign list, the on/off switch for sending (Admin-only).*

## A4.6.3

The campaign detail (Steps, People, Preview and Email Queues) looks **the same as the SDR view**, see SDR [Flow 6 ↗](6-manage-a-campaign.md) for every tab.
