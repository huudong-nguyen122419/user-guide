# C4.2 · Stale work

> C4 · Keep the pipeline moving

There is no *aging* filter. Sort the **Open** tab by **Modified Date**, oldest first, and the top of the list is your problem list. **Paused** deserves the same treatment: a paused project is one somebody meant to come back to.

Compare **Created Date** with **Modified Date** on the same row. A project created months ago and modified months ago has been quietly abandoned; created months ago but modified this week is simply a long engagement.
