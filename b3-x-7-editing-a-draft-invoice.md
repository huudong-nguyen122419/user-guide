# B3.x.7 · Editing a Draft invoice

> B3 · Timesheet → invoice (Admin) → B3.x · Edge cases

**Editing an invoice that is still in Draft.** A **Draft** invoice remains fully editable — open the drawer [as in B3.x.6 ↗](b3-x-6-open-invoice-from-timesheets.md), make the change, then click **Update** (top right). The drawer closes and the Timesheets row updates. After editing, **download the PDF again** ([B3.4.3 ↗](b3-4-review-invoice-and-pdf.md)) to be sure the file matches the corrected figures — the PDF is regenerated from the latest data. Draft onlyEdit freely while the invoice has not been sent. Once it moves to the next status it belongs to the **Issue Client Invoices** flow and is no longer freely editable.

| What you can change | Effect |
|---|---|
| **Service period start / end date** | Changing the range **recalculates Quantity**, and any expense falling in the new range is pulled in (see [B2.x.8 ↗](b2-x-8-expense-on-a-non-worked-day.md)). |
| **Billing rate · Quantity** | Amount recalculates from the new values. |
| **Description · Client contact · Fintalent Bank Account** | Changes what is printed on the PDF. |
| **Additional items** | Add / remove / edit non-fee items. |
| **Type** (Standard Invoice…) | Changes the invoice type. |
