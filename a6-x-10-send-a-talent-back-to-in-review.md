# A6.x.10 · Send a talent back to In Review

> A6 · Talent Active / Passive → A6.x · Edge cases

**Sending a talent back to In Review.** **More Actions → Switch to In Review** opens a drawer listing the talent's applications, with the rule stated at the top: *“Can't switch if application status is Connected / In Interview / Draft Agreement / Hired”*. Confirm with **Switch** and the status returns to In Review, which brings the Approve / Reject buttons back. The internal status is left untouched. The rest of that menu: Delete · Delete Permanently · Parse CV · Upload CV · Update gender · Skip Project Invites · Hero from website · Hidden from website.
