# B3.x.1 · Daily = days

> B3 · Timesheet → invoice (Admin) → B3.x · Edge cases

**Daily contracts: Quantity is in DAYS.** **One working day = 8 hours.** Example: the talent logs 8h (Jul 13) + 6h (Jul 14) = 14h and locks in to bill 8h + 4h = **12h** → Quantity = **12 ÷ 8 = 1.5 days** → Amount = 1.5 × 500 USD = **750 USD**. On the PDF the column changes from **HOUR(S)** to **DAY(S)**.
